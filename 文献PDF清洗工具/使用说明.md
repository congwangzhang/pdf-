# 文献PDF清洗工具 · 使用说明

把本地一堆 **SCI 文献综述 PDF** 提取成干净的结构化内容：
**题目 / 摘要 / 关键词 / 各级标题树 / 表格标题与内容 / 图片标题 / 参考文献**。
全程鼠标操作，不用写任何代码。

---

## 第一次使用（只需做一次）

**Windows**：
1. 打开 https://www.python.org/downloads/ ，点黄色按钮下载 Python
2. 运行安装包 —— ⚠️ **务必勾选安装页底部的 "Add Python to PATH"**
3. 双击 `一键运行.bat` —— 它会自动装好需要的 PDF 引擎（首次约 1 分钟）

**Mac**：双击 `启动工具.sh`（若打不开，右键 → 打开方式 → 终端）。

## 日常使用：4 步

1. 双击 `一键运行.bat`
2. 点「选择…」，选中放 PDF 的文件夹（会自动找到里面所有 PDF）
3. 点「▶ 开始清洗」，等进度条走完
4. 打开结果文件夹（工具里有「📁 打开结果文件夹」按钮），查看成果

每篇文献都可以在「② 看结果」里**逐篇查看**：左边选文献，中间是结构树，
右边可以在**清洗文本 / 原始提取文本 / 摘要**之间切换对照。

---

## 四个标签页

| 标签页 | 干什么 |
|---|---|
| ① 导入与清洗 | 选文件夹、开关清洗规则、批量处理、看日志 |
| ② 看结果 | 逐篇查看：结构树 + 清洗/原始文本对照 |
| ③ 标题树汇总 | **所有文献的标题树合集**（写综述定大纲的参照） |
| ④ 质检与导出 | 每篇的质量报告和问题清单、导出结果 |

## 输出结果长什么样

```
清洗结果/
├── 某文献名/
│   ├── clean.json      ← 结构化全量数据（题目/摘要/标题树/表图/参考文献…）
│   ├── 清洗文本.md      ← ⭐ 清洗后的全文（Markdown 格式：标题层级/摘要/图注/表格/参考文献）
│   ├── 原始文本.txt     ← 原始提取全文（含被剔除的噪声，可对照/回退）
│   ├── 标题树.md        ← 这篇文献的各级标题（含编号、页码、层级）
│   └── 质检报告.md      ← 质量指标 + 问题清单
├── 汇总_标题树.md       ← ⭐ 所有文献的标题树合集（构建你综述大纲的核心参照）
└── 汇总_文献清单.csv    ← 一览表（题目/关键词/标题数/表格/图片/参考文献数）
```

**原始 PDF 永远不会被修改**，输出全部写到独立的「清洗结果」文件夹。

## 清洗工具会自动处理哪些问题

- ✅ **双栏排版**：左栏读完再读右栏，不再左右交叉错乱
- ✅ **页眉页脚/页码/DOI/版权**：跨页重复 + 位置 + 规则识别，自动剔除
- ✅ **无用信息整块剔除**：版权/许可声明（Creative Commons 等）、通讯作者、单位脚注、
  等同贡献、Author details / Ethics / Competing interests 等声明区，全部清出正文
- ✅ **断词换行**：`infor-` + `mation` 自动合并成 `information`；引用断行 `[10, 21-` + `23]` → `[10, 21-23]`；
  复合词连字符保留（如 senescence-related）
- ✅ **连字乱码**：`ﬁ` `ﬂ` 等字符还原，软连字符/零宽字符清除；多余空格/换行全部规范化
- ✅ **断行合并**：被 PDF 换行/分块切碎的句子合并回完整段落，
  `immunotherapy. Moreover`、`senescent T cells`、`[5, 43](Fig. 2)` 等不再被空格/换行断开
- ✅ **图表不打断正文**：figure legend（图例）和表格从正文中间**整体抽离**，
  正文跨过它们继续连贯；**图注/表格统一放在文章最后**（参考文献之后）
- ✅ **综述固定结构识别**：首页题目/摘要/关键词；结论后参考文献前的
  Abbreviations / Acknowledgements / Authors' contributions / Funding /
  Availability of data / Ethics / Competing interests / Author details /
  Received-Accepted 日期等**全部过滤**；正文行（如 60 years…）不会误判为标题
- ✅ **表格格式化**：能还原行列的表格输出为标准 Markdown 表格；复杂表格保留原始行文本；
  只有一两行的“假表格”自动剔除；表格列头的 References 不会被误认为参考文献区
- ✅ **标题层级**：编号（1 / 1.1 / 1.1.1）+ 字号 + 加粗/斜体 综合判断，生成标题树；
  **无编号标题**（仅加粗/加大/斜体区分的）同样能识别，跨行标题自动合并；
  按篇自适应标题样式，综述标题一般较短（一句话不会太长）；
  表格单元格、正文片段、参考文献条目、年份/数量行都不会误判为标题
- ✅ **参考文献**：从 References 处切出，单独保存；引用标记不丢失

## 遇到这些情况请知晓

- **扫描版 PDF（图片型）**：没有文字层，本版会标记"疑似扫描页"，暂不处理。
  此类文献建议先用带 OCR 的工具（如 Adobe Acrobat）转成文字版再清洗。
- **标题带 ⚠️ 的**：表示层级是按字号/加粗推断的，建议人工核对一下。
- **公式**：尽量原样保留，不做转换（转换反而容易坏）。
- **表格提取**：常规表格能按行保留；复杂合并单元格的表格请对照原 PDF 核实。
- 完全自动化做不到 100% 准 —— 工具的原则是：**原文不丢失、修改有记录、
  异常可定位、结果可复核**。拿不准的地方都留在"原始文本"里，随时可对照。

## 常见问题

**Q：双击 一键运行.bat 没反应 / 窗口一闪就没了？**
A：按顺序排查：
1. ⚠️ 必须先把压缩包**完整解压**到本地文件夹（比如桌面）再运行，
   不能在压缩包的预览窗口里直接双击（那样程序文件不在旁边，跑不起来）。
2. 双击同一文件夹里的 `诊断.bat`，把窗口截图或 `诊断报告.txt` 发给 AI。
3. 也看看文件夹里有没有生成 `启动日志.txt`，一并发给 AI。

**Q：点开始后很慢？**
A：正常，一篇 20 页的 PDF 约几秒到十几秒。批量处理时进度条会走。

**Q：处理失败/某篇跳过了？**
A：看「① 导入与清洗」右侧日志或 `启动日志.txt`。单篇失败不影响其他文献。
   可以点「▶ 开始清洗」续跑（已处理的自动跳过）。

**Q：重新处理某篇文献？**
A：点「全部重新处理」，或删掉清洗结果里该文献的文件夹后重跑。

**Q：结果能给别的软件用吗？**
A：`clean.json` 是标准 JSON，包含全部结构化字段（标题树/分节段落/表图/参考文献），
   可以直接导入 Excel、数据库或后续做知识库。

## 给进阶用户 / AI 协作者

- 核心逻辑全部在 `core/` 目录（`extract / clean / classify / quality / export / pipeline`），
  不含界面，可单独调用：`from core.pipeline import process_pdf`。
- 数据分层：`raw_text`（原始）永不修改；`clean_text` 为规则清洗结果；
  每条清洗规则可单独开关，修改次数记录在 `line_clean_stats`。
- PDF 引擎优先级：PyMuPDF（保留字体/坐标/栏位）→ pdfminer.six（降级）。
- 结构分类字段说明见 `clean.json`：`headings[].level/number/parent_id` 构成标题树，
  `confirmed="待确认"` 表示推断结果需要人工确认。
